---

Read desktop UI text with App Bridge Free. Call the `app` MCP tool `Snapshot` (optionally with `region` if the user named an area). Summarize visible labels and text nodes from the result. Do not click or type. If the accessibility tree is sparse, say so. Pro input tools are placeholders — do not invent them.
