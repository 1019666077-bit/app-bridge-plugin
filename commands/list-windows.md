List open windows with App Bridge Free. Call the `app` MCP tool `Snapshot` and report the **active/open window titles** from the tool result (`Screenshot` alone skips window enumeration). Do not click, type, focus, or launch apps. WeChat may appear as a normal title — treat it as an optional example only, not a supported control target. Tell the user this is Free observe-only.
